# aus-energy-met

Collaborative research project investigating how Australia's weather impacts solar and wind energy generation and energy demand



This project is structured as following:

```bash
aus-energy-met/
├── analysis
│   ├── example.ipynb
│   └── figures
│       └── .figures
├── .copier-answers.yml
├── data -> /g/data/ng72/$USER/aus-energy-met/data
│   ├── derived
│   └── raw
│       └── DO_NOT_EDIT
├── .envrc
├── .git
├── .gitignore
├── README.md
├── requirements.txt
├── src
│   └── aus-energy-met
│       ├── __init__.py
│       └── sample_fun.py
└── tests
    └── aus-energy-met
        └── test_sample_fun.py
```

The data folder may not be present in the repository but instructions and or documentation are provided.
